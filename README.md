# Seed and Succeed Tycoon

A Unity-based tycoon game built for the **Superseed Crypto Contest**. Grow your digital empire by mastering the Superseed protocol, playing addictive minigames, and strategically reinvesting your fortune.

---

## 🎮 About The Game

**Superseed Crypto Tycoon** is a simulation game where your goal is to build a massive financial empire from the ground up. You'll start small, but by engaging with a simplified, in-game version of the Superseed crypto protocol, you can accelerate your wealth.

The core loop is simple:
1.  **Play** engaging minigames to earn your initial capital.
2.  **Invest** that capital into assets like businesses, real estate, and more.
3.  **Leverage** your assets using the game's unique "Superseed Loan" feature to expand faster.
4.  **Reinvest** your profits to become the ultimate tycoon!

This game aims to educate players on the core concepts of the Superseed protocol—like self-repaying loans, liquidity provision, and bridging—in a fun and accessible way.

## ✨ Core Features

* **Tycoon Gameplay:** Start with nothing and build a sprawling empire. Buy, manage, and upgrade various assets to increase your passive income.
* **Protocol-Based Minigames:** Your "work" in the game consists of minigames based on real Superseed protocol actions:
* **The "Superseed Loan" Mechanic:** True to the protocol, you can take out special "self-repaying loans" in the game. Use your existing assets as "Supercollateral" to get a massive injection of cash. This loan will slowly pay itself back using a portion of your total income, allowing you to expand aggressively.
* **Asset Marketplace:** A dynamic in-game market to buy and sell unique assets for your empire.
* **Leaderboard:** Compete with other players (if implemented) to see who can build the largest fortune.

## 📦 Installation & Setup
Play without and installation required at: https://victor-pausan.itch.io/seed-and-succeed-tycoon

OR

To run this project locally, you'll need [Unity Hub](https://unity.com/download) and the correct Unity Editor version.

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/Victor-Pausan/Seed_and_Succeed_Tycoon
    ```
2.  **Open the project in Unity Hub:**
    * Open Unity Hub.
    * Click "Add" or "Open".
    * Navigate to the cloned repository folder and select it.
3.  **Install the correct Unity Editor version** (if prompted by Unity Hub).
4.  **Open the project** in the Unity Editor.
5.  **Run the game:**
    * Open the main scene (e.g., `Assets/Scenes/Main.unity`).
    * Press the "Play" button at the top of the editor.
